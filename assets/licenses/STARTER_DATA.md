# Starter data attribution

`assets/data/seed_entries.json` contains original demonstration entries written
for MyDuo and dedicated to the public domain under CC0-1.0.

Production data packs built from Kaikki/Wiktextract must retain each source URL,
license, and attribution field. Wiktionary-derived material is generally
CC BY-SA and may also include GFDL material; pack distributors must review and
ship exact notices applicable to their source dump.

No Cambridge Dictionary text, branding, audio, or layout is included.
